# 作品 ZIP

把拾趣导出的「分镜与图片 ZIP」原样放到：

```text
works/<GitHub 用户名>/<作品编号>.zip
```

例如 `works/alice/tang-lang-bu-chan.zip`。用户名和作品编号使用小写；作品编号用英文、数字及单个连字符，最多 64 字符。作者署名来自用户名目录。标题、原著、旁白、图片顺序和改编说明从 `分镜.md` 读取。

每个 ZIP 最多 25 MiB，最多 80 幅；图片支持 PNG、JPEG、WebP，单张最多 12 MiB。请提交普通 STORE 或 DEFLATE ZIP，不使用密码、ZIP64 或分卷。

只上传 ZIP 即可，不需要提交封面、JSON 或解压后的图片。合并后，自动工作流生成书架目录与封面，阅读器直接下载 ZIP 并在浏览器里展开。

ZIP 中的全部内容会被公开保存，包括原始导出中可能包含的制作要求和画面提示词。阅读页面只显示作品内容，但这不意味着 ZIP 中的其他内容保密。

完整操作见 [贡献指南](../CONTRIBUTING.md)。这里不放测试或演示作品。
