# Static story publication

Story: static-story-publication. Git base: 8837a5e (preserve across reviews).
Risk: non-low: public manifest/loading contract, untrusted content and deployment retention change together.

## Decision

Validate original ZIPs unchanged, then publish only allowlisted manifests and referenced images under `public/<id>/<version>/`. Version hashes cover public metadata, image hashes, and ZIP identity. Build canonical pages from the same public manifest. Normal reading uses HTTP images and native lazy loading; ZIP parsing/Blob URLs remain for explicit local preview only.

Remote readers fetch the selected repository's GitHub Pages `catalog.json`, so catalogue and assets become visible through the same deployment. Each manifest URL identifies an immutable version; failures do not substitute another manifest. Retain earlier immutable resources from previous dist locally and from a dedicated `static-publication` snapshot branch in CI; neither deploy nor that branch contains original ZIPs. Retention counts toward 950 MiB and fails closed instead of removing cached-page dependencies. Source ZIP capacity is checked independently. No new runtime dependencies.

Browsers choose lazy-load distance, so verify that no application loop fetches every image, not an exact browser-specific request count. Retention can eventually exhaust deployment capacity; fail explicitly and require an owner decision. Dedicated publication branch is generated by CI only, never a source for reviewed stories.
