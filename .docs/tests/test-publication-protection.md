# 阅读站公开声明 E2E

前置：本站实际浏览器导出的合成2幅 ZIP，带公开署名、保存原文、来源许可、联系/作品链接、转载条件、AI披露、版本、底部12px署名、XMP和SHA-256。仅使用合成图，不调用生成服务。

1. 在项目子路径打开reader.html?preview=1并选择fixture。两幅图解码，署名/来源/AI/原文保留，无隐形水印编号或检测入口。窄屏不溢出，文件不上传。
2. 实际archive解析、prepareStory/importStory和临时workspace构建保留公开信息与WebP原始字节。公开清单排除提示词，声明的最终SHA不符时拒绝。以正确CRC重打包篡改样本，确保是SHA检查拒绝。
3. 检查独立manifest路径：校验后显示同一字节，限制每图12MiB/合计100MiB，拒绝跨源/越界/重复引用，失败释放BlobURL。无hash旧图仍可读。
4. 空署名、旧格式、AI未知/false、恶意文本及链接保持现有安全行为。代码许可不扩展为作品授权。
5. pnpm test和pnpm build通过；生产作品恢复到已提交版本，hero QR保留。回退验证见完成文档。
