# 阅读站署名与转载保护

当前阅读站把投稿目录名作为署名，忽略新版导出中的制作人、转载条件、AI 披露和图片校验信息。阅读站应保留作品声明及原始图片，不替用户扩大授权，也不覆盖实际制作人。

- [x] 新版唯一 ZIP 在浏览器试读、目录收录和兼容导入路径中保留公开制作署名、来源许可、联系方式、作品链接、转载条件、原文、版本身份和明确的 AI 披露；投稿者与制作人分开。缺失署名不能凭投稿目录补造。历史 ZIP/清单仍可读。
- [x] JSON/XMP 中的最终图片哈希、原图/图片载荷哈希在解析中保留，声明的最终图片哈希不符时拒绝；图片不重编码，原 ZIP 保持同一路径和文件名，仅一份。
- [x] 阅读页安全显示署名、来源/许可、转载条件、联系及作品链接，说明代码许可不自动覆盖作品，哈希不是权属证明。无记录不宣称已有授权。
- [x] 新公开清单只允许已知公开字段，排除提示词/内部生成记录；旧格式兼容，错误链接/哈希/结构拒绝，文本不执行 HTML 或脚本。
- [x] 用本站实际新导出的合成 ZIP 验证真实解析、导入、构建及浏览器本地试读，核对 WebP 字节/元数据和项目子路径。完成 pnpm test/pnpm build，不引入第三方运行时依赖。
- [x] 更新投稿与内容说明：新导出默认去除内部提示词，但既有 ZIP 不会因阅读器隐藏字段变私密。原文/来源版本/制作贡献适用各自规则。不得改动既有收录作品、推送或发布。

范围是阅读站功能及说明。不添加水印模型或检测功能。不是 DRM、权利认定或自动授权。测试 ZIP 只放 tests/fixtures/，不写 stories/works 或发布目录。
