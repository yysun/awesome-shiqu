# 浏览器操作要点

执行头条发布时读取。以下方法来自 2026-11-04 的实际页面；每次以当前工具文档和 UI 为准，不能沿用旧元素索引、tab ID 或浏览器 ID。

## 会话与观察

首次使用 `mcp__cua_repl` 时只调用一个入口 API，例如 `await cua.getState()`，读完返回文档再继续。Chrome 任务按工具要求命名会话。扩展改权限后可能重新注册：旧浏览器不可用时，列出浏览器，按相同 profile/extension identity 重新连接同一页，不换账号。

已观察到文章入口 `https://mp.toutiao.com/profile_v4/graphic/publish?from=toutiao_pc`。优先使用页面提供的「写文章」链接，不保证地址永久不变。

AX 快照曾延迟于真实页面。控件仅获焦点、定位器无匹配或页面似乎不变时，用 DOM snapshot/截图核对，不按旧索引重复点击。观察实际加载状态再决定下一步。

## 读取公开作品包

```bash
python3 <本技能目录>/scripts/prepare_shiqu_article.py \
  '<已选公开作品.zip>' --out '<新的私有临时目录>' --author '好画好心情'
```

输出 `article.json` 与 `images/001.webp` 等有序图片。不要放在仓库的 `stories/` 或 `dist/`。这只是提取已有公开作品，不替代拾趣的制作和导出入口。

工具允许文件 I/O 时可读清单到浏览器 REPL；只读取本次清单，不读取浏览器 profile、cookies 或凭证。否则用文件工具读取精简清单再作为数据传入，不手工重打几十段旁白。

## 批量图文

曾观察到标题 `textarea[placeholder="请输入文章标题（2～30个字）"]`，正文 `div.ProseMirror`。先从当前 DOM 确认后使用。工具栏图标按钮可能缺少可访问名称，可通过截图或当前 DOM 定位图片/链接图标，不长期依赖按钮序号。正文有焦点后再插图。

上传前读当前环境的 `file-uploads` 文档。用文件选择器批量上传有序图片，确认支持多选。等上传计数全部完成再插入，不把「已选文件」当作上传成功。

Chrome 曾要求开启 ChatGPT 浏览器扩展的 **Allow access to file URLs**。遇到错误时读取上传故障文档，让用户按指引开启；不擅自扩大扩展权限。完成后确认会话和编辑器状态，再重试一次。

大量图片可先全部插入，再将已上传图片与旁白交错组成 HTML，通过正常粘贴替换正文：

1. 只读编辑器可见图片的顺序、`src`、实际宽高及公开图片属性，不读应用内部状态。
2. 注意隐藏模板与可见副本重复。本次可见图片在 `mask img` 中；按实际 DOM 去重，不能一幅算两幅。
3. 清单 `caption` 转义为正文段落，逐幅配对。保留宽高及有效图片属性。仅复制 `outerHTML` 曾造成粘贴后 `img_height` 为 0，要从实际图片宽高校验修正后的粘贴结果。
4. 正文区获得焦点，正常全选与 HTML 粘贴；不通过脚本修改 DOM、内部状态或伪造保存记录。
5. 复核唯一图片数、加载结果、图文对应及旁白原文。平台可能重新处理图片并换 URL，不把 URL 改变自动当作换图。

少量图文直接逐段插入即可。不要为试错重复上传整套图。

## 链接与选区

HTML 粘贴曾剥离普通 `<a>`，需要单独建立署名链接。

- 「内部链接」用于头条主页，文字「好画好心情」，地址使用用户提供或已核实的公开主页。
- 「外部链接」用于 awesome-shiqu。此模式提示文字自动取目标页标题，不支持自定义文字，不承诺任意锚文本。
- 内部链接会拒绝非头条 URL，不能用它绕过外链解析。
- 读正文链接文字和真实 `href` 核对，看到原来的文字不算成功。

先核对实际选区再插链接。可只读 `window.getSelection()` 检查选中内容和位置，不用脚本修改选区。该次 `Meta+ArrowLeft/Up`、AX `selectText` 的结果不稳定，点击目标段落后用 `Home`、普通方向键可以正确选择；快捷键行为需按当前平台核实。

外链解析持续旋转时，保留网址和草稿，明确告知限制。裸网址文本是降级结果，不能报告为可点击链接或外链卡片成功。

## 设置与提交

应用 `SKILL.md` 偏好，读取真实 `checked` 状态并结合截图核对。特别在更换封面后核对单图/三图。

「作品声明」曾是互斥选择，虽然 DOM 使用 checkbox。点「虚构演绎」会取消「引用AI」；AI 作品优先 AI 声明，正文说明改编。

平台助手曾把「姑娘们」中的「娘们」误报为不文明用语，也在有 36 张图时建议配图。结合上下文判断，不机械修改正确文字以消除提示。

「预览并发布」后可能先提示广告设置，再出现手机预览和「确认发布」。用户若选择不投广告，可能出现「将不会产生广告收益」提醒；已有该设置授权时按工具规则继续，不误当成购买或合同。

最终提交后仍可能出现：

> 请完成国内手机号绑定或实名认证，否则将无法发布内容。

在这里保存草稿并交接，不宣称发布成功，不替用户提供身份数据，不连续重试。截图用于核实阻碍；用户完成后恢复同一草稿，先检查是否已发布再提交。
